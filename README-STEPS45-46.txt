BeyondGB — Steps 45–46

STEP 45 — JOURNEY COMPARISON
- Public Journeys page now allows visitors to select up to 3 journeys.
- Compare selected journeys in a responsive comparison table.
- Comparison includes destination, duration, difficulty, price and description.
- Direct Explore buttons are included in the comparison.
- No database or subscription is required.

STEP 46 — JOURNEY SHARE & PRINT
- Public journey detail pages now have Print journey and Share journey controls.
- Share uses the device's native share sheet when supported.
- On browsers without native sharing, the journey URL is copied when clipboard access is available.
- Print mode hides navigation/CTA clutter and produces a cleaner journey summary.
- No database or subscription is required.
