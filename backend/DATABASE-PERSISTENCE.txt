BEYONDGB DATABASE - AUTHORITATIVE PROJECT DATA

This beyondgb.db is the current authoritative database for this project.
It contains the current admin accounts and existing enquiry records, plus the CMS tables required by the current version.

IMPORTANT:
- Do NOT delete or replace backend/beyondgb.db when updating website files.
- Future update ZIPs should preserve this database unless a database migration is explicitly requested.
- Before installing any future update, make a backup copy of backend/beyondgb.db.
- The server uses backend/beyondgb.db by default unless BEYONDGB_DB_PATH is intentionally configured.
- Database initialization uses CREATE TABLE IF NOT EXISTS and migrations; it must never reset or drop existing content.
