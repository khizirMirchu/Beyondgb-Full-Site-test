# BeyondGB Steps 41–42

## Step 41 — Advanced Tour Pricing
Optional numeric amount, currency and price note fields are now stored with tours while the existing price text remains compatible.

## Step 42 — Tour Availability
Admin can add/edit/delete upcoming dates, seat counts and availability status for each journey. Public journey pages display upcoming dates.

## Requested UI fixes retained
Homepage testimonials use See more / See less for long reviews. The admin dashboard layout from Steps 39–40 is otherwise unchanged.

## Database
`backend/beyondgb.db` is intentionally NOT included. Keep your master database separate and stop the server before copying it between versions.
